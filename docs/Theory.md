## Этап 1. Каркас проекта

**Модули курса:** 1.1 (Qt/Quick), 1.3 (структура проекта), 1.4 (язык QML), 1.5 (визуальные типы).

**Изучил:**
- Qt - кроссплатформенный фреймворк. Qt Quick - современный UI-стек (декларативный QML, рендер через GPU). Qt Widgets - классический (императивный C++, рендер на CPU). Для анимаций и кастомного дизайна берут Quick.
- **PySide6** - официальные биндинги Qt для Python. QML-код идентичен C++-версии.
- QML - декларативный язык: описываю, **что** хочу, а Qt сам решает, **как** это нарисовать.
- **Property binding** - главная фишка QML. Свойство может быть выражением от других свойств; Qt пересчитывает автоматически при изменении зависимостей. Пример: `height: width * 0.5`.
- **Структура проекта:** `qml/` (UI), `backend/` (Python), `data/` (SQLite), `docs/` (конспекты).
- **Визуальные типы:** `Rectangle` (прямоугольник), `Text` (надпись), `Image` (картинка), `Canvas` (рисование), `Item` (невизуальная база для всех).
- Импорты без версий (`import QtQuick`, без `2.15`) - современный стиль Qt 6.

## Этап 2. Воспроизведение MP3

**Модули курса:** 4.2 (Мультимедиа), 3.4 (Button, Slider), 3.1 (FileDialog).

**Изучил:**
- **MediaPlayer** знает, ЧТО играть (source). **AudioOutput** знает, КУДА выводить звук. Два объекта, работают в паре.
- `source` - это URL (`file:///C:/Music/track.mp3`), не путь.
- **playbackState** - три состояния: `StoppedState`, `PlayingState`, `PausedState`. Методы `play()`, `pause()`, `stop()`.
- `position` и `duration` - в миллисекундах. Сигналы `onPositionChanged`, `onDurationChanged`, `onMediaStatusChanged`.
- **Slider - position: подписка на `onMoved`, а не `onValueChanged`.** `onValueChanged` срабатывает и при программном изменении — получили бы бесконечный цикл.
- **FileDialog** - системный диалог выбора файла. `selectedFile` - URL. `nameFilters` - массив фильтров.
- **Хрип при смене source** - FFmpeg пересоздаёт поток ~50 мс. Маскируем: глушим звук перед сменой, возвращаем через таймер.
- **Material-стиль** (`import QtQuick.Controls.Material`, `Material.theme: Material.Dark`) - решает проблему невидимого текста на тёмной теме Windows.

## Этап 3. Плейлист

**Модули курса:** 2.5 (Модели), 2.6 (Представления), 1.6 (Позиционирование).

**Изучил:**
- **ListModel** хранит данные как набор **ролей** (полей) и **элементов** (строк). Уведомляет UI о любом изменении - представление перерисовывается само.
- **ListElement** - один элемент модели. У всех элементов одного `ListModel` должны быть одинаковые роли.
- Методы модели: `append`, `insert`, `remove`, `set`, `setProperty`, `get`, `clear`. Свойство `count`.
- **ListView** связывает модель (`model`) с шаблоном элемента (`delegate`).
- **Делегат** - шаблон одной строки. Qt создаёт ~10-15 экземпляров на видимую область и переиспользует их при прокрутке.
- **В делегате роли модели доступны как обычные свойства:** если в элементе есть `title` - в делегате пишем `text: title`.
- Спецпеременные в делегате: `index` (номер), `ListView.isCurrentItem`.
- **Позиционирование:** `anchors` (привязка к родителю), `Row`/`Column` (расстановка детей по горизонтали/вертикали со `spacing`).
- **FileDialog с `fileMode: OpenFiles`** позволяет выбрать несколько файлов сразу. Результат - `selectedFiles` (массив URL).

## Этап 3.5. Рефакторинг на компоненты

**Модуль курса:** 2.4 (Компоненты).

**Изучил:**
- Любой `.qml`-файл с **заглавной буквы** автоматически становится компонентом - можно использовать как тег.
- Файлы в подпапке подключаются через `import "имя_папки"`.
- **Компонент ничего не знает об остальном приложении.** Получает данные через `property`, о действиях сообщает через `signal`.
- `property var` - для передачи объектов (плеер, модель) в компонент.
- `signal trackClicked(int index)` - объявление сигнала. Снаружи подписка через `onTrackClicked: ...`.
- **Правило:** UI - в компоненты, логика (функции, модель, таймеры, MediaPlayer) - в `main.qml`.

## Этап 4. mutagen - теги и обложки

**Модуль курса:** 4.1 (Работа с файлами). Плюс интеграция QML↔Python.

**Изучил:**
- **URL vs путь.** FileDialog отдаёт URL (`file:///C:/...`), Python работает с путём (`C:/...`). Конвертация: `urlparse` + `unquote`, на Windows убрать ведущий слэш.
- **`unquote`** - превращает `%20` - пробел, `%D1%82` - `т`.
- **ID3-тег** - блок метаданных внутри MP3. Едет вместе с файлом.
- Ключи: `TIT2` (название), `TPE1` (исполнитель), `TALB` (альбом), `APIC` (обложка).
- **mutagen** - библиотека для чтения тегов. `MP3(path)` открывает файл, `.tags` - теги, `.info.length` - длительность в секундах.
- **`str(audio.tags["TIT2"])`** - тег это объект, не строка. `str()` даёт нормальное значение.
- **APIC** - встроенная обложка. Содержит `mime` и `data` (сырые байты).
- **Кэш обложек.** QML `Image` не грузит из байтов, только из файла. Python сохраняет обложку в `data/covers/<hash>.jpg`, возвращает путь. Хеш от пути MP3 - уникально и стабильно.
- **QObject** - базовый класс Qt для всего, что имеет сигналы и слоты. Python-объект, видимый в QML, обязан наследовать `QObject`.
- **`@Slot(type, result="Type")`** - декоратор, делающий метод вызываемым из QML. Типы: `str`, `int`, `float`, `bool`. Для словарей - `result="QVariantMap"`, для списков - `result="QVariantList"`.
- **`setContextProperty("bridge", obj)`** - регистрация Python-объекта в QML как глобальной переменной. **До** `engine.load()`.
- **Разделение ответственности:** `media.py` (чистая логика, без Qt) и `bridge.py` (мост с Qt, без UI). Тестируемо, переиспользуемо, читаемо.
